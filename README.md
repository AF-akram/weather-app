## 🌤️ Weather App

A simple and interactive Weather Application built with React.js that allows users to search for any city and check its current weather conditions.

The application uses the OpenWeatherMap API to retrieve real-time weather information and OpenStreetMap Nominatim to convert city names into geographic coordinates.

# ✨ Features
🔍 Search for weather information by city name.
🌡️ Display current temperature in Celsius.
📉 Display minimum and maximum temperatures.
☁️ Show current weather conditions and descriptions.
🌥️ Display weather icons based on current conditions.
📅 Display the current date and time.
🌍 Retrieve geographic coordinates using OpenStreetMap.
⚛️ Manage global city state using React Context API.
🎨 Styled interface using Material UI and custom CSS.
# 🛠️ Technologies Used :
React.js – Building the user interface.
Material UI (MUI) – UI components and icons.
Axios – Handling HTTP requests.
React Context API – Global state management.
Moment.js – Formatting date and time.
OpenWeatherMap API – Retrieving weather information.
OpenStreetMap Nominatim API – Geocoding city names.
CSS – Custom styling.
# 🌐 APIs Used
OpenWeatherMap API – Provides current weather data.
OpenStreetMap Nominatim – Converts city names into latitude and longitude.
